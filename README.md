# Британская империя, 1921

Интерактивная карта владений Британской империи на React + TypeScript + Vite.
Статический MVP без backend и внешних API: границы берутся из локального TopoJSON,
описания стран и локаций лежат в исходниках.

## Что показывает карта

- 49 имперских записей на срез **1921 года** — год вершины империи (около 35 млн км²).
  Заливкой выделены метрополия, доминионы, колонии, протектораты, мандаты
  Лиги Наций и зависимые территории.
- Статус владения (`EMPIRE_STATUS_LABELS`): метрополия, доминион, колония,
  протокторат, мандат, зависимая территория, кондоминиум, часть Соединённого
  королевства.
- Подписи на карте — только метрополия, доминионы и крупнейшие владения,
  остальные перечислены в панели страны и в легенде.
- Мелкие владения и анклавы без отдельной геометрии (Гонконг, Мальта, Гибралтар,
  Бермуды и другие) вынесены в подпись под картой: в Natural Earth 1:110m их нет.

**Важно:** геометрия — современная Natural Earth. Исторические очертания колоний
не воспроизводятся, поэтому площадь заливки не равна площади владения в 1921 году.
Выход из состава Соединённого королевства Ирландии (1922) и раздел Индии (1947)
отмечены в описаниях, но на карте видны по современным границам.

## Возможности

- Векторианский стиль: бумага и сепия, шрифт с малой прописной, гравированная
  штриховка владений и двойные рамки вместо скруглённых карточек.
- Слой стран Natural Earth 1:110m с зумом и ограниченным панорамированием.
- Стартовый вид — Британские острова в центре (`DEFAULT_ZOOM = 4.5`).
- Панорамирование доступно только при зуме от 1.2, карта не уходит за край сферы:
  пределы считает `src/features/map/mapBounds.ts`.
- Выбор страны кликом или клавишей `Enter`/`Space`, панель с описанием.
- Поиск по стране, столице, городу, континенту, ISO-кодам и тегам.
- Фильтры: континент, тип локации, «только со столицей», «только с описанием».
- Маркеры локаций (столицы, города, горы, реки, природные объекты): точка
  не зависит от зума и не разрастается при приближении.
- Плавный перелёт к объекту: `useAnimatedView` интерполирует центр и зум,
  уважая `prefers-reduced-motion` и сокращая путь по долготе.
- Сброс карты и сброс фильтров по отдельности.

## Запуск

```bash
npm install
npm run dev        # дев-сервер
npm run test       # Vitest + Testing Library
npm run typecheck  # tsc -b --noEmit
npm run lint       # ESLint
npm run build      # tsc -b && vite build
npm run preview    # предпросмотр сборки
```

## Данные

`public/maps/world.topo.json` — Natural Earth 1:110m Countries в формате
TopoJSON (world-atlas, public domain). Геометрии содержат ISO 3166-1 numeric-3,
поэтому сопоставление со статическим набором идёт через `src/data/isoNumeric.ts`
(alpha-3 → numeric-3). Территории без сопоставленной записи остаются неинтерактивными
и помечены в `aria-label`.

Статические данные:

| Файл | Содержимое |
| --- | --- |
| `src/data/empire.ts` | год среза, название империи, список мелких владений |
| `src/data/empireTerritories.ts` | 41 территория вне существующих стран |
| `src/data/countries.ts` | 68 стран, из них 49 имперских записей |
| `src/data/empireLocations.ts` | локации имперских владений |
| `src/data/cities.ts` | 88 локаций (столицы, города и объекты) |
| `src/data/continents.ts` | 7 континентов |

Население и площади округлены и не пригодны для статистического анализа.

## Структура

```
src/
  app/            App и его стили
  components/     карта, поиск, фильтры, панель страны, легенда
  data/           статические данные, имперский срез и ISO-маппинг
  features/       фильтрация, селекторы, границы карты и анимация вида
  hooks/          состояние приложения и загрузка карты
  styles/         глобальные переменные темы
  test/           фикстуры и настройка jsdom
  types/          доменные типы
  utils/          поиск страны и форматирование
```
